# Juliana Abrenica Portfolio

A Next.js portfolio for my AI-generated content work and practical business support across Canva, Word, Excel, presentations, and campaign assets.

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy To Vercel

1. Push this folder to a GitHub repository.
2. Import the repository in Vercel.
3. Keep the default Next.js settings and deploy.

The sample work images live in `public/work`.
